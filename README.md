## Процессор

### Получение исполняемого файла

Исполняемый файл можно получить с помощью команды 
```
make
```
Для исполнения необходимо иметь в основной папке txt файл с кодом на облегченном ассемблере (подробнее далее). Запуск командой 
```
./processor filename.txt
```

### работа процессора

Процессор выполняет программы, написанные на облегченном ассемблере - поддерживается основной пулл команд, в том числе прижки и функции. 
Команды:


|   Команда | Действие                                                                                            |
|:---------:|:---------------------------------------------------------------------------------------------------:|
| push      | Помещение числа (push 5), значения из оперативной памяти (push [0]) или регистра (push ax) в стек   |
| pop       | Помещение числа из стека в регистр (pop ax) или ячейку оперативной памяти  (pop [0])                |
| add       | Сложить два последних числа из стека, результат сохранить в стеке                                   |
| sub       | Вычесть из предпоследнего числа из стека последнее, результат сохранить в стеке                     |
| mul       | Перемножить два последних числа из стека, результат сохранить в стеке                               |
| div       | Поделить предпоследнее число из стека на последнее, результат сохранить в стеке                     |
| out       | Вывести последнее в стеке число                                                                     |
| hlt       | Завершить программу                                                                                 |
| j_        | Условный и безусловный прыжки, аналогично ассемблеру, агрумент - лэйбл                              |
| call      | Вызов функции                                                                                       |
| ret       | Возврат из функции                                                                                  |

Для действия функций во время исполнения создается специальный стек возвратов, чтобы фиксировать адреса возвата из функций.

Данные могут храниться в регистрах ax, bx, cx, dx и оперативной памяти. Причем поддерживаются только целые числа. 

При исполнении асссемблерный код преобразовывается в цифровой. Он в свою очередь исполняется, при этом используется стек. Моя реализация стека - <https://github.com/gnnpdr/stack>.

Также есть дизассемблер - он преобразует цифровой код обратно в ассемблерный, лэйблы и функции при этом именуются стандартно и нумеруются по порядку появления в коде.
